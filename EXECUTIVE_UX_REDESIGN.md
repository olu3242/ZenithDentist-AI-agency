# Executive UX Redesign

## Status

Implemented for the default dashboard shell.

## Executive Experience

The default dashboard is now an Executive Command Center for practice owners and a role-specific operating surface for other roles. It replaces the old generic KPI board with:

- Outcome-focused persona KPIs
- Mission-domain drilldowns
- ALICE recommendation priority
- Workflow queue
- Reports linked to operating decisions

## Practice Owner Default Flow

Practice Owner login:

1. `/dashboard`
2. Executive Command Center
3. Revenue, Patients, Operations, Automations, Reports
4. Strategy and implementation decisions

## KPI Drilldown Model

| Executive KPI | Drilldown |
| --- | --- |
| Revenue Recovery | Revenue, reports, forecasting, simulations |
| Patient Recovery | Patients, recall, reviews, retention |
| Automation ROI | Workflow OS, Runtime OS, Automation Center |
| Locations | Location benchmarking and operations |

## Design Rule

Every widget must answer one of four operating questions:

- How do we grow revenue?
- How do we retain patients?
- How do we improve operational execution?
- How do we increase automation leverage?
