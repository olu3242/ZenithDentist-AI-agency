# ALICE Chief Intelligence Model

## Status

Implemented in `lib/agent-workforce.ts`.

## ALICE Role

ALICE becomes Chief Operating Intelligence.

## Responsibilities

- Coordinate agents
- Prioritize actions
- Resolve conflicts
- Simulate outcomes
- Learn from results

## Conflict Resolution

- Compliance Agent can block unsafe actions.
- Recovery Agent can override routine timing during incidents.
- ALICE resolves revenue vs capacity conflicts through simulation.
- Human approval is required above tenant autonomy threshold.

## Boundary

ALICE coordinates intelligence. Execution still goes through Automation Platform, Runtime OS, Governance OS, and tenant policy.
