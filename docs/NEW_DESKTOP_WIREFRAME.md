## Grid System

- Max content width: `max-w-7xl` (1280px)
- Padding: `px-5` (20px each side)
- Section padding: `py-20` (80px top/bottom)
- Hero: `min-h-[calc(100vh-72px)]`
- Column gap: `gap-8` (32px)

## Color Usage

- Page background: `var(--brand-sidebar)` (dark navy)
- Elevated surfaces: `var(--brand-sidebar-elevated)`
- Assessment / LIZ sections: `bg-background` (light)
- Final CTA: `bg-[color:var(--brand-sidebar-elevated)]` or darker
- Accent: `text-teal` (brand teal)
- Headlines: `text-white` or `text-ink` depending on section
