# Agent Framework

## Status

Defined in `lib/platform-os/foundation.ts` and supported by `lib/ai-os/*`.

## Agent Types

- Revenue Agent
- Growth Agent
- Operations Agent
- Compliance Agent
- Recovery Agent
- Forecasting Agent
- Support Agent

## Shared Resources

All agents share:

- Memory
- Policies
- Knowledge
- Telemetry

## Governance Rule

Agents may recommend, coordinate, and execute within policy boundaries. They may not bypass Automation Platform, Governance OS, tenant policy, or audit logging.
