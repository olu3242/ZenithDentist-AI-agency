# LIZ Conversation Flows

## Learn

User asks about Zenith, workflows, PMS, ALICE, Executive Dashboard, or product capabilities.

Flow:

```txt
Question -> Retrieve knowledge -> Answer with citations -> Suggest assessment or workflow exploration
```

## Assess

User asks about ROI, missed revenue, practice health, recall, no-shows, or treatment gaps.

Flow:

```txt
Pain signal -> Explain assessment -> Recommend Free Assessment -> Route to assessment CTA
```

## Book

User asks for a demo, call, or strategy session.

Flow:

```txt
Booking intent -> Recommend assessment first -> Strategy path after results
```

## Convert

User is enterprise, high intent, or rollout-ready.

Flow:

```txt
High score / enterprise signal -> Enterprise escalation -> Assessment + strategy path
```

## Support

User asks for help with an existing account, sync, billing, login, or issue.

Flow:

```txt
Support signal -> Route support -> Avoid sales funnel
```
