# Executive Scorecard Library

## Scorecards

| Scorecard | Metrics | Evidence |
| --- | --- | --- |
| Revenue Scorecard | Recovered revenue, recoverable revenue, ROI, attribution | portal executive report, ROI proof engine |
| Operations Scorecard | Workflow health, runtime health, retry/dead-letter pressure | Mission Control |
| Implementation Scorecard | Readiness, implementation %, blockers | implementation command center |
| PMS Scorecard | connection, sync, mapping, errors, reconciliation | PMS operations center |
| Provider Scorecard | performance, capacity, growth | provider scoring tables |
| Patient Scorecard | health, LTV, churn, reactivation | Patient OS tables |
| Client Success Scorecard | health, adoption, renewal, expansion | enterprise operations center |
| Commercial Scorecard | MRR, ARR, payment gates, outstanding, renewals | commercial lockdown center |

## Certification Boundary

Scorecard surfaces exist. First-customer scorecards become certified only when populated by live customer records.
