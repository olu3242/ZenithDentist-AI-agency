## Certification Definitions

- CERTIFIED: UI, backend, persistence, telemetry, permissions, and execution/reporting path exist in code and migrations.
- PARTIALLY CERTIFIED: Core implementation exists, but production proof, full workflow attribution, or environment validation is incomplete.
- DEMO ONLY: Primarily seeded/fallback/generated presentation without production persistence.
- PLACEHOLDER: Surface exists without meaningful backend implementation.
- BROKEN: Implementation or validation fails.
