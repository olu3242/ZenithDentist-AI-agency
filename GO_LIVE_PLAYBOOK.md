# Go-Live Playbook

## Entry Criteria

- Contract signed.
- Setup fee paid.
- Client account approved.
- Subscription active.
- Organization created.
- Implementation project created.
- PMS vendor identified.

## Day 0 Setup

1. Confirm client contacts, billing contact, support contact.
2. Assign package blueprint.
3. Create implementation project.
4. Confirm required integrations.
5. Confirm required workflows.
6. Open go-live checklist.

## Technical Readiness

1. Verify PMS credentials.
2. Test patient sync.
3. Test appointment sync.
4. Test provider sync.
5. Test treatment data.
6. Connect email.
7. Connect SMS.
8. Connect Stripe.
9. Verify templates.

## Workflow Readiness

1. Enable recall workflow.
2. Enable appointment reminders.
3. Enable treatment follow-up.
4. Enable reviews.
5. Enable reactivation.
6. Verify Workflow OS execution evidence.

## Training Readiness

1. Practice owner dashboard training.
2. Practice owner revenue reporting training.
3. Office manager Workflow OS training.
4. Front desk patient communication training.
5. ALICE usage walkthrough.

## Launch Approval

Launch only after:

- `computeImplementationScorecard()` returns ready for go-live.
- All required go-live checklist items are complete.
- Mission Control events are visible.
- Revenue attribution event path is verified.
- Customer success review is scheduled.

## Exit Criteria

- First live workflow executed.
- First evidence record generated.
- First revenue attribution record generated or explicitly zero-state.
- Client has access to portal.
- 30-day success review scheduled.
