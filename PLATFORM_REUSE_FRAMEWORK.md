## Status

Implemented by `lib/platform-os/foundation.ts`.

## Reuse Targets

- Zenith
- Owambe OS
- EduRadius
- FinClarity
- Oasis Go
- Future products

## Pattern

```txt
Shared OS Foundation
  -> Product Domain Pack
    -> Tenant Configuration
      -> Persona Command Center
        -> Autonomous Workflow
```

- Domain entities
- Workflow templates
- Marketplace packs
- Persona labels
- Benchmarks
- Policies

- Autonomy model
