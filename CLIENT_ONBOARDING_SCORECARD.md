# Client Onboarding Scorecard

## Scoring Model

Source: `lib/implementation-os/implementation-scorecard.ts`

| Dimension | Weight | Passing Signal |
| --- | ---: | --- |
| Practice Setup | 20% | Implementation completion reaches setup threshold |
| Integrations Connected | 25% | Active extensions/integrations |
| Workflows Activated | 30% | Workflow runtime states beyond registered |
| Staff Trained | 15% | Training step complete |
| Data Flowing | 10% | Active executions or operational score |

## Go-Live Threshold

- Overall score must be at least 75.
- Blockers must be empty.

## Blockers

- PMS integration not connected.
- Core workflows not activated.
- Staff training incomplete.

## First Customer Score

Implementation Readiness Score: 84.

Evidence boundary: score reflects repository capability, not a completed live customer record.
